# Support

Use GitHub issues for reproducible bugs and focused feature requests. Or write a message in the discord server [ZeroSyntax](https://discord.gg/FShKq5s2hH)

Before opening an issue:

- Check the latest release.
- Search existing issues.
- Try to reduce the problem to a small INI sample.

For general modding help, game troubleshooting, or questions unrelated to the
language server or VS Code extension, use the relevant community channels for
Command & Conquer: Generals - Zero Hour.
